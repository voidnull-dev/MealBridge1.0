# MealBridge

## Platform
web

## Stack
User mandated plain static HTML, CSS, and JavaScript; no frameworks, bundlers, or package-based build. CDN libraries where useful.

## Purpose and users
Connect hostels and food providers with NGOs to rescue safe surplus meals before they are wasted. Turning Surplus into Support.

## Scope
Phase 1 foundation and landing page are preserved. Phase 2 adds Google-only Firebase Authentication and private Firestore user-profile onboarding for hostels and NGOs, plus the intended verified Google admin profile bootstrap. No dashboards, surplus listings, claims, maps, ratings, or admin panel. Authentication uses modular Firebase CDN imports without a build setup. Firestore rules require manual Console deployment. A profile's admin badge is never a privileged authorization boundary.

## Brand commitments
Luxury cinematic dark sustainability direction; electric emerald accent, bold modern sans-serif typography, restrained motion, premium light and system themes. Respect reduced motion. No copied automotive branding.

## Evidence
The supplied brief provides static availability of 127 meals and illustrative 24-person rescue story. Other counters and testimonial personas are labeled demo content. No real endorsements or measured impact supplied.
